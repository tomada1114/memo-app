# コードレビュー

$ARGUMENTS 配下のコードを以下の4つの観点でレビューしてください。
プロジェクトのコーディング規約は[coding-rules.md](references/coding-rules.md)を参照してください。

## レビュー観点

1. **バグの可能性**: エラーハンドリングの不足、エッジケースの見落とし、型の不整合がないかチェック
2. **可読性**: 変数名や関数名がわかりやすいか、処理の流れが追いやすいかを確認
3. **命名規則**: プロジェクト内で命名が統一されているかをチェック
4. **改善点**: よりシンプルに書ける箇所、パフォーマンスを改善できる箇所を提案

## 出力形式

各観点ごとに、以下の形式で報告してください。

- 問題の概要
- 該当箇所（ファイル名と行番号）
- 改善案
